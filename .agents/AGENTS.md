# Reglas del Proyecto: Motor de Carruseles

## Estilo Visual y Diseño

- **Estilo Obligatorio:** Maximalismo Brutalista (Alto impacto visual, tipografías gigantes ultra-pesadas, elementos superpuestos, pegatinas de advertencia y bordes gruesos).
- **Paleta de Colores Exclusiva:**
  - Fondo: Negro Absoluto (`#000000` / `#050505`).
  - Color de Acento / Destacado: Verde Fosforito Neón (`#39FF14` / `#00FF66`).
  - Detalles y Bordes: Blanco Puro (`#FFFFFF`) y sombras desplazadas estilo brutalista neón (`shadow-[14px_14px_0px_#39FF14]`).
- **Formato de Salida:** Carruseles estricto 1080x1350 px (4:5 Portrait).
